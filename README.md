# Mahamagham — Client Ready Demo

Premium responsive static website for the Thirunavaya Mahamagha Mahotsavam.

## Open in VS Code
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Recommended: install the **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.

The site also uses relative links, so pages can be opened directly, but Live Server gives cleaner browser behavior and avoids `file://` console warnings.

## Pages
- `index.html` — premium landing page
- `about.html` — what Mahamagham is + Thirunavaya context
- `festival.html` — rituals, sacred days and Nila Aarathi
- `pilgrim-guide.html` — travel and visitor guidance
- `get-involved.html` — volunteer / offerings / sponsorship
- `gallery.html` — visual gallery
- `contact.html` — enquiries and contact

## Design focus
- Strong first-screen identity: **The Kumbh Mela of the South**
- Clear explanation of Mahamagham, Magha, Nila and Thirunavaya
- Premium Keralam heritage palette and cinematic imagery
- Mobile-first layout tested for 320px, 375px, 430px and tablet widths
- Sticky mobile actions appear only after the hero on the home page
- Responsive menu, cards, sections, forms and gallery
- No build tools or npm required

## Important
Festival dates/timings are intentionally not hard-coded until the organising team confirms them. Remote Mahamagham image assets are used with local SVG fallback artwork.
